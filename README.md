# Portfolio de Carolina Silvestri

Proyecto editable del portfolio personal y copia estática del respaldo del 9 de septiembre de 2026.

- La raíz contiene el proyecto editable con React, TypeScript y vinext.
- `sitio-compilado/` conserva la versión estática del respaldo.
- `LEEME.txt` describe el respaldo original.

## Desarrollo

Requiere Node.js 22.13 o superior.

```sh
npm ci
npm run dev
```

Para compilar: `npm run build`.

La configuración original de Sites se conserva en `.openai/hosting.json`.
